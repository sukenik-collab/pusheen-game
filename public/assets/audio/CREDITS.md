# Audio — placeholders & recommended real tracks

The `.wav` files here now are **synthesized CC0 placeholders** (generated by
`scripts/gen-placeholder-audio.mjs`). They exist so the Phase-5 audio plumbing
and the in-game selector work end-to-end. Swap in real files later: keep the
same filename (or repoint it in `src/config/audioManifest.js`) and no code
changes are needed.

## SFX sets

| Selector | Recommended pack | License |
|----------|------------------|---------|
| Soft  | Kenney — "UI Audio" — https://kenney.nl/assets/ui-audio | CC0 (no attribution) |
| Boopy | Kenney — "Interface Sounds" — https://kenney.nl/assets/interface-sounds | CC0 (no attribution) |

Each SFX set needs one clip per event key in `SFX_EVENTS`
(`land, jump, squish, sniff, peek, nope, collect, sigh`). Map real files to
those keys in `audioManifest.js`.
